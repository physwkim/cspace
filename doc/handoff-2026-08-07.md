이 문서를 쓰는 사이에도 두 번 낡았다. 지금 값은 이 명령이 준다:

    for b in $(git branch --list 'caucus/*' --format='%(refname:short)'); do
      n=$(git rev-list --count main..$b)
      [ "$n" -gt 0 ] && printf '%-52s %s  %s ahead\n' \
        "$b" "$(git rev-parse --short $b)" "$n"
    done
